# 2026 데이터+AI 혁신 챌린지 공모 요건

이 문서는 소상공인 폐업위험 조기신호 프로젝트에 적용되는 데이터 문제해결 부문의 요구사항을 작업 기준으로 정리합니다. 공고가 변경되면 공식 페이지와 첨부 PDF를 우선하고 이 문서를 갱신합니다.

확인 기준일: `2026-09-17`

## 출처 우선순위

1. [한국데이터산업진흥원 공식 공고 및 최신 첨부파일](https://www.kdata.or.kr/datahub/portal/support/board/10/48)
2. 저장소에 보관한 [통합공고문 PDF](../references/2026-data-ai-innovation-challenge-notice.pdf)와 [참가신청 양식 PDF](../references/data-problem-solving-application-form.pdf)
3. 공식 포털의 참가 신청 화면과 신청 가이드
4. 저장소 문서, Notion 계획, Linear 이슈

공식 게시글 본문은 서면·발표평가 연도를 `2025`로 표기하지만, 2026 통합공고 PDF의 전체 일정은 `2026-10-27` 이후로 일관됩니다. 이 저장소는 첨부된 2026 통합공고 PDF를 기준으로 일정 연도를 해석합니다. 일정은 변경될 수 있으므로 제출 전에 공식 페이지를 다시 확인합니다.

## 대회 개요

| 항목 | 내용 |
| --- | --- |
| 대회 | 2026 데이터+AI 혁신 챌린지 - 데이터 문제해결 |
| 주최/주관 | 과학기술정보통신부 / 한국데이터산업진흥원 |
| 참가 대상 | 대한민국 국민 누구나 |

| 접수처 | AI·데이터 문제해결은행 포털의 지식마당 경진대회 메뉴 |

데이터레시피 제안 부문과 분석도구 활용 부문은 중복 참가할 수 없습니다. 이 프로젝트는 분석도구 활용 부문만 진행합니다.

## 신청 절차

1. AI·데이터 문제해결은행 포털에 회원가입합니다.
2. 팀 참가라면 팀 대표자의 계정으로 신청합니다.
3. 데이터레시피와 워크스튜디오 워크플로를 먼저 완성합니다.
4. 포털의 `지식마당 > 경진대회`에서 참가 정보를 직접 입력합니다.
5. 워크플로 결과 JSON을 업로드하고 워크플로 URL을 입력합니다.
6. 제출 후 접수 상태와 제출 시각을 캡처해 증빙으로 보관합니다.

참가신청 양식 PDF 자체를 업로드하는 방식이 아니라 포털 신청 화면에서 해당 내용을 직접 작성합니다. 실제 화면의 필수 항목이 참고 양식과 다르면 포털을 따릅니다.

## 프로젝트와 부문 적합성

분석도구 활용 부문의 공고 예시는 건강, 환경, 문화여가, 생활안전, 재난재해, 에너지, 주거교통, 가족, 교육, 사회통합 등의 사회현안 해결입니다. 소상공인 폐업위험은 예시에 직접 열거되어 있지 않으므로 다음을 문제정의에서 명확히 해야 합니다.

- 폐업위험이 지역 일자리, 생활상권의 지속가능성 및 취약계층 생계에 미치는 사회적 영향
- 단순 사업성 예측이 아니라 선제 지원을 위한 사회현안 해결이라는 목적
- 분석 결과를 실제 지원기관의 의사결정으로 연결하는 방법

부문 적합성은 분석 착수 전 공식 문의처를 통해 확인하는 것을 권장합니다.

## 신청서 작성 항목

포털 신청 화면에서 다음 서술 항목을 각각 300자 이상 작성합니다.

1. 신청 개요: 추진 배경, 데이터 활용 과정과 특징, 기대효과 요약
2. 추진 배경 및 문제 정의: 문제의 중요성과 현재 한계
3. 데이터 분석 기획: 목표, 데이터 선정 이유·확보 방법, 도구·기법·절차
4. 데이터 개요 및 활용 방안: 출처·획득·전처리·분석 절차, 모델·알고리즘·파라미터 선정 이유
5. 예상 또는 실제 성과 및 기대효과: 경제·사회적 가치, 확산 가능성, 후속 계획

## 필수 제출물

- 포털에서 작성한 참가신청서
- 포털에서 생성한 데이터레시피
- 워크스튜디오 워크플로 결과 파일(JSON)
- 워크스튜디오 워크플로 URL
- 발표평가 대상자로 선정될 경우 발표자료

공식 양식은 신청서 작성 전에 데이터레시피와 워크스튜디오 워크플로 생성을 완료할 것을 권장합니다.

## 데이터·권리·윤리 준수사항

- 데이터는 별도로 제공되지 않으며 참가자가 직접 확보합니다.
- 개인정보·민감정보는 비식별화하고, 저작권 및 이용권한이 해결된 데이터만 사용합니다.
- 분석은 문제해결은행 포털의 워크스튜디오 분석도구를 사용해 제출합니다.
- 문제해결은행 전문가 지원으로 개발한 활용사례·데이터레시피는 출품할 수 없습니다.
- 동일 아이템으로 유사 공모전에 입상한 결과물이나 타인의 권리를 침해한 결과물을 제출할 수 없습니다.
- 생성형 AI를 사용했다면 사용 여부와 범위를 명확히 공개합니다.
- 생성형 AI 활용 사실을 누락하거나 허위로 기재하면 심사 제외 또는 수상 취소 사유가 될 수 있습니다.
- 제출작과 데이터는 포털 콘텐츠, 생성형 AI 모델 학습, 합성·재현 데이터 생성과 공익 목적 가공에 활용될 수 있으므로 신청 화면의 동의 범위를 제출 전에 확인합니다.
- 비식별화·합성 데이터 작업을 위해 제출 데이터가 별도로 최대 5년간 보관될 수 있습니다.
- 공개 전 보호가 필요한 아이디어는 참가자가 직접 지식재산권 확보 여부를 판단합니다.

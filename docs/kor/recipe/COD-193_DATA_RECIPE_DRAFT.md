# COD-193 문제 해결레시피 초안

확인 기준일: `2026-09-18`

이 초안은 문제 해결레시피 작성 가이드의 본문 흐름에 맞춘 작업본이다. 아직 모델을 실행하지 않았으므로 성능 수치와 효과는 목표 또는 검증 항목으로만 적는다.

## 기본 정보

- 레시피 유형: AI 기반 문제 해결레시피
- 레시피명: `매출·생활인구·경쟁도로 찾는 소상공인 폐업위험 조기신호`
- 활용 목적: 위험 최소화
- 데이터 유형: 상권·업종별 분기 시계열 공개 데이터
- 키워드: `소상공인,폐업위험,상권분석,추정매출,생활인구,조기경보`
- 분석 후보: 단순 기준선과 Random Forest 분류 모델
- 산업 분류: 포털 상세 선택지 확인 후 확정

## 무엇을 해결하는가

상권×업종별 매출 하락, 길단위인구 감소, 동종업 경쟁 심화 신호를 분기별로 결합해 다음 분기의 폐업 발생 위험을 상대적으로 비교한다. 지자체와 지원기관은 고위험 집단을 상담·경영개선 안내·상권 현장점검의 우선 검토 대상으로 활용할 수 있다.

## 왜 필요한가

소상공인 지원은 폐업이 확인된 뒤 제공되는 사후 지원에 머물기 쉽다. 매출·생활인구·점포 변화는 각각 공개되지만 같은 공간·업종·시간 단위로 연결해 선제 지원 근거로 바꾸는 재현 절차가 필요하다. 이 레시피는 개인이나 개별 사업자를 평가하지 않고 집계 단위에서 위험 신호와 불확실성을 함께 제시한다.

## 필요한 데이터

| 데이터 | 핵심 컬럼 | 단위 | 주의점 |
| --- | --- | --- | --- |
| 점포-상권 | `STDR_YYQU_CD`, `TRDAR_CD`, `SVC_INDUTY_CD`, `STOR_CO`, `OPBIZ_RT`, `CLSBIZ_STOR_CO` | 분기×상권×업종 | 공개 폐업률은 확률로 해석하지 않음 |
| 추정매출-상권 | 공통 키, `THSMON_SELNG_AMT`, `THSMON_SELNG_CO` | 분기×상권×업종 | 추정매출이며 전수 실매출이 아님 |
| 길단위인구-상권 | 분기·상권 키, `TOT_FLPOP_CO` | 분기×상권 | 업종 차원이 없어 상권 공통 변수로 결합 |

모두 서울 열린데이터광장 자료이며 공공누리 1유형 출처 표시가 필요하다. 별도 외부 시스템은 필수가 아니다. 현재 검증에서는 2024~2025 매출 키 172,911개가 점포 키와 모두 결합됐고, Q1 길단위인구의 점포 상권 결합률은 99.97%였다. 이는 데이터 실행 가능성의 측정값이지 모델 성능이 아니다.

## 6 STEP 문제 해결 절차

1. **데이터 확보·표준화**: 점포·매출·길단위인구의 컬럼명, 분기 형식, 상권·업종 코드를 통일한다.
2. **품질·결합 검사**: 중복·결측·극단값, 키별 결합률, 2024년 공간 단위 변경 전후의 연속성을 점검한다.
3. **타깃·조기신호 생성**: `t+1` 폐업 발생 여부와 `t`까지의 매출 증감·변동성, 인구 증감, 점포 수·개업률 변수를 만든다.
4. **시간 기준 학습·검증**: 과거 기간으로 학습하고 이후 기간으로 검증하며 단순 기준선과 후보 모델을 비교한다.
5. **성능·안정성 평가**: 상위 위험군의 정밀도·재현율, F1, PR-AUC와 업종·자치구·표본 규모별 편차를 평가한다.
6. **결과 해석·활용**: 위험 5분위, 주요 신호, 표본 수와 불확실성을 함께 제공하고 사람이 최종 지원 여부를 검토하게 한다.

세부 구현은 [COD-194 코드 기반 분석 파이프라인 설계](COD-194_ANALYSIS_PIPELINE_DESIGN.md)를 따른다.

## 결과 화면 계획

1. 상권×업종별 위험 5분위와 주요 신호 히트맵
2. 시간 검증 기간별 기준선·후보 모델 성능 비교
3. 위험 5분위별 실제 다음 분기 폐업 발생률
4. 업종·자치구별 성능과 표본 오차
5. 과대·과소 위험 사례와 레시피의 한계

## 성과지표

1. 상위 20% 위험군이 실제 폐업 발생 행을 얼마나 포착하는지 측정
2. 단순 기준선 대비 정밀도·재현율·F1 또는 PR-AUC 개선 여부 측정
3. 상권×업종 우선 검토 목록에 주요 근거·표본 수·불확실성이 함께 표시되는지 점검

목표 수치는 분석 전에 임의로 쓰지 않고 1차 시간 검증 결과와 함께 확정한다.

## 활용방안과 기대효과

- 단기: 현장 확인, 상담 안내, 경영개선 프로그램 홍보의 우선 검토 목록 제공
- 중장기: 분기별 위험 신호와 실제 지원·성과를 연결하는 피드백 체계 구성
- 확산: 같은 컬럼 계약을 충족하는 다른 지역·업종에 절차 이식
- 통제: 개별 사업자 자동 판정, 대출·지원 자동 배제, 표본이 작은 집단의 단정적 해석을 금지

기대효과는 아직 측정 전이다. 분석 후 기준선 대비 개선과 정책 활용 가능성을 별도로 검증한다.

## 한계와 책임 있는 사용

- 추정매출과 길단위인구는 생성 방법에 따른 오차가 있으며 실제 경영성과를 완전히 대변하지 않는다.
- 폐업 발생은 임대료, 경영자 의사결정, 경기 충격 등 공개 데이터에 없는 요인의 영향을 받는다.
- 위험점수는 집계 단위의 상대 순위이며 개별 사업자의 폐업확률이 아니다.
- 생성형 AI는 문서 구조화와 코드 보조에 사용하고, 데이터 판단·분석 결과·제출 문구는 사람이 검토한다.

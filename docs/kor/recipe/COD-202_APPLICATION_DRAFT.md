# COD-202 참가신청 서술 초안

작성일: `2026-10-14` (Asia/Seoul). 개인·팀 구분, 참가자 실명·연락처, 대표 계정, 서약·동의 항목은 본인 확인 후 포털에 입력한다. 아래는 기존 보관 신청 양식의 5개 서술 항목에 맞춘 검토본이다. 실제 포털의 최신 필드와 글자 수 규칙은 미확인이다.

## 1. 신청 개요

본 과제는 서울시의 공개 상권·업종별 점포 자료와 추정매출 자료를 결합하여 다음 분기의 폐업 발생 신호를 비교하고, 지자체와 소상공인 지원기관의 선제 점검을 돕는 데이터레시피를 제안한다. 분석 단위는 상권·서비스업종·분기이며 개별 사업자의 폐업확률을 판정하지 않는다. 2024~2025년 공식 원천을 표준화하고 중복과 결측, 연속 분기 여부를 검사한 뒤, 과거 자료로 학습하고 이후 분기에 평가하는 재현 절차를 구현하였다. 평가 자료 147,032행에서 검증 AP로 선택한 매출 제외 회귀의 평가 Average Precision은 0.4862였으며, 상위 20% 집단은 전체 폐업 발생 행의 약 63.91%를 포함하였다. 다만 점포 수·업종 기준선의 성능이 비슷하여 추가 변수의 기여는 제한적이었다. 성과를 과장하지 않고 규모 편향과 자료 공개 지연을 함께 제시하며, 지원 담당자가 현장 확인과 상담 안내의 우선순위를 검토하는 보조 자료로 활용하도록 한다.

## 2. 추진 배경 및 문제 정의

소상공인의 경영위험을 살피려면 점포 변화와 매출 같은 서로 다른 공개 자료를 같은 지역·업종·시점으로 연결하고, 어떤 집단을 먼저 확인할지 설명할 수 있어야 한다. 본 과제는 서울 상권·서비스업종 집계에서 다음 분기에 폐업 점포가 하나 이상 관측되는지를 문제로 정의하였다. 이는 개인의 경영 능력이나 사업 지속 의사를 평가하는 문제와 구분된다. 공개 폐업률은 100을 넘는 값이 있고 공식 분모 정의를 충분히 확인하지 못하여 확률 타깃으로 사용하지 않았다. 또한 점포 수가 큰 집단은 폐업이 하나라도 발생할 가능성이 높으므로, 높은 예측점수가 곧 개별 점포의 취약성을 뜻하지 않는다. 이러한 구조를 명확히 설명하고 업종과 점포 규모별 평가를 병행하여, 소규모 상권의 지원 기회를 줄이지 않는 점검 체계를 설계한다. 공개 자료에서 확인한 통계적 신호와 현장 판단을 연결하는 것이 목적이며, 자동 지원 배제나 금융 심사의 근거로 사용하는 것은 본 과제의 활용 범위에 포함하지 않는다.

## 3. 데이터 분석 기획

분석 목표는 다음 분기 폐업 발생 집단의 상대 순위를 산출하고, 단순 기준선과 비교하여 추가 신호의 효용과 한계를 확인하는 것이다. 서울 열린데이터광장의 점포-상권 및 추정매출-상권 자료를 선정한 이유는 공통 분기·상권·서비스업종 키를 가지며 공식 공개 출처에서 확보할 수 있기 때문이다. Python과 pandas로 파일의 컬럼과 코드를 표준화하고 scikit-learn의 로지스틱 회귀로 해석 가능한 후보를 구현하였다. 학습은 2024년, 검증은 2025년 1분기, 평가는 2025년 2~3분기의 피처를 사용하며 각각 바로 다음 분기 폐업 발생을 라벨로 삼는다. 중앙값 대체와 표준화는 학습 자료에만 적합하고, 모델과 임계값은 검증 자료에서 정한 뒤 평가 기간에는 고정하였다. Average Precision, F1, 상위 20% 정밀도와 포착률, 위험 분위별 관측 발생률을 보고한다. Work Studio의 동일 절차 재현과 실제 파일 공개시점을 반영한 검증은 남은 작업으로 분리하여 관리한다.

## 4. 데이터 개요 및 활용 방안

사용 자료의 기간은 2024년부터 2025년까지이며, 점포 611,664행과 추정매출 172,911행을 로컬에서 재검사하였다. 두 자료 모두 분기·상권·서비스업종 키의 중복과 결측은 없었다. 매출 키는 점포 자료에 모두 결합되지만 점포 키 중 매출을 보유한 비율은 약 28.27%이므로, 결합률의 방향을 구분하고 매출이 없는 행을 매출 0원으로 바꾸지 않는다. 다음 분기 자료가 연속해서 있는 행에 타깃을 만들고, 현재 점포가 1개 이상인 행을 분석한다. 점포·개업·폐업 수와 추정매출의 로그값, 연속 분기 매출 변화, 최근 변화의 변동성을 피처로 사용하였다. 로지스틱 회귀는 C=0.1·1·10을 검증 AP로 비교하고 lbfgs, 최대 반복 1,000회로 설정하였다. 업종은 범주형으로 처리하며 검증 AP가 가장 높은 매출 제외 C=10 모델을 후속 검토 후보로 삼았다. 업종 과거 평균, 현재 폐업 발생, 동일 가중 신호, 점포 수·업종 회귀를 비교 기준으로 두었다. 기존 확인 기준 이용조건은 공공누리 1유형이며 출처를 표시한다. 공식 길단위인구를 확보하지 못하여 미리보기 인구 자료는 분석 근거에서 제외하였다.

## 5. 예상 또는 실제 성과 및 기대효과

검증 AP로 선택한 매출 제외 회귀는 고정 평가 기간에서 Average Precision 0.4862, F1 0.4663을 기록했으며 상위 20% 집단의 정밀도는 약 32.88%, 양성 포착률은 약 63.91%였다. 전체 후보 AP는 0.4856, 점포 수·업종 기준선 AP는 0.4830이었다. 동일 C에서 전체 후보와 매출 제외의 AP 차이는 −0.000613, 상권 500회 재표집 95% 구간은 [−0.001035, −0.000162]로, 이번 자료에서는 매출 추가의 예측력 개선을 확인하지 못했다. 따라서 매출 변화가 폐업을 유발하거나 정책 개입으로 폐업을 감소시킬 수 있다는 결론은 제시하지 않는다. 기대효과는 공개 자료의 반복 가능한 분석, 점검 대상의 근거 제공, 상담·현장 확인 업무의 지원이며 실제 경제·사회적 효과는 운영 이후 별도 측정할 계획이다. 규모별 임계값은 소규모 집단의 포착률을 높이지만 점검량 증가·정밀도 하락이 있어 처리 용량 검토가 필요하다. 공개시점 지연과 지역 외 일반화 한계를 보완하고, 공식 인구 자료와 추가 기간을 확보하여 후속 검증한다. 생성형 AI는 코드·테스트·문서 초안 작성과 결과 요약에 사용하였으며 최종 데이터 해석과 제출 문구는 사람이 검토한다.

## 모델과 환경 비교

학습 분기에만 중앙값 대체·표준화·업종 원핫 인코딩을 적합했다. 수치 피처는 log_stores·log_closures·log_openings이고 업종 외 키·분기·타깃·점포 수는 모델 피처에 넣지 않았다. L2 로지스틱 회귀 C=10, lbfgs, max_iter=1000, random_state=0으로 실행했다. 임계값은 검증 F1 최대값으로 정하고 평가에 고정했다.

같은 입력과 스크립트를 로컬에서 재실행했을 때 기존 로컬 수치가 재현됐다. 스튜디오와 로컬의 실행 환경 차이는 확인했지만, 라이브러리 버전·CSV 실수 파싱 등이 수치 차이에 미친 영향을 분리 실험하지 않았다. 따라서 스튜디오 지원 분석 실행 성공과 완전히 동일한 모델 재현은 구분한다. 기존 로컬 지표를 스튜디오 실측값으로 표기하거나, 평가 기간이 새 독립 검증이라고 주장하지 않는다.

분석 실행·저장·대조 및 위 검토 승인을 근거로 COD-197을 Done으로 전환했다. 후속 코드 PR은 별도로 남아 있다. 이 승인은 포털 제출·개인정보·서약·동의 확정이나 Git push·PR·merge 승인을 포함하지 않는다.

## Git 반영 전 검증

feature 브랜치 반영 전에 입력 키 결측·중복과 증빙 파일 변조·실패 상태·증빙 부재 검사를 추가했고 전체 테스트 42개와 `git diff --check`를 통과했다. 재사용 함수는 문자열 변환 전에 키 결측을 검사하도록 보강했으며, 실제 스튜디오 실행 원문은 기존 증빙 경로에 보존한다. 원천·생성 데이터·화면 증빙·인증정보는 커밋에서 제외한다. 사용자의 별도 Git 반영 요청에 따라 feature 브랜치 push와 자동 Draft PR 생성 절차를 진행하며 merge는 별도 승인 대상이다.

# PR #20 병합 전 리뷰 반영

- 입력 검증을 `assert`에서 `ValueError`로 바꾸고 고정 행 수 제약을 제거했다. 학습·검증의 비어 있는 분할, 이진 타깃 및 양쪽 클래스 유무를 검사한다.
- 공식 원천 ZIP의 CSV 개수와 CRC를 확인한 뒤 임시 파일을 교체한다. 잘못된 응답이 기존 원천 파일을 덮어쓰지 않도록 했다.
- 실제 Studio에서 실행한 코드는 Git 제외 증빙의 `executed_script.py`로 보존한다. 저장소 재현 함수의 검증 보강을 Studio 재실행으로 주장하지 않는다.
- 증빙 검증은 기록된 입력·결과 파일의 해시 일치 확인이다. 실행자의 서명 검증이나 모델 동등성을 보증하지 않으며 `not_exact` 표시는 유지한다.

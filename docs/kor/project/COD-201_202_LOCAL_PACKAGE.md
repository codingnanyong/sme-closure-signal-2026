## 재생성

```powershell
.\.venv\Scripts\python -m sme_closure_signal prepare-submission
```

생성기는 모델 입력 SHA-256과 분석 메타데이터의 일치를 확인하고, 신청서 글자 수를 검사하며, 템플릿·스키마 예시와 3개 시간분할 입력을 생성한다. 매니페스트에는 파일별 크기·SHA-256, 모델군, 이미지 개수, Work Studio 입력 행 수를 기록한다. 자료의 상대 참조를 유지하기 위해 공개 저장소 문서와 기존 보관 공식 공모 PDF를 `reference_repository/`에 함께 보관한다. 인증키·`.env`·제한된 로컬 가이드 PDF·실제 관측 CSV는 제출 묶음에 복사하지 않는다.

폴더와 함께 `outputs/submission/stores-sales-v1.zip` 및 ZIP의 `.sha256`을 생성한다. ZIP은 로컬 검토·인계용으로, 포털의 공식 제출 형식이 ZIP으로 확정됐다는 뜻은 아니다.

현재 후보는 점포·개업·폐업 수와 업종의 매출 제외 회귀 C=10이고, v1 평가 AP는 0.486218이다. 추가 데이터 실험은 v1의 원천·평가표를 덮어쓰지 않고 별도 경로에 저장한다.

최종 점검에서 파일 46개의 SHA-256 일치, 루트 본문 5종의 내부 링크 유효성, PNG 4개, 학습·검증·평가 296,131·73,647·147,032행을 확인했다. ZIP 내 인증정보·원천 데이터·실제 관측 학습·평가 CSV는 없으며 합성 예시에는 `SYNTHETIC` 식별자를 사용했다. 테스트 28개와 `git diff --check`를 통과했다.

- 신청 주체·대표 계정·개인정보·서약·동의와 사람 검토 기록.
- 공식 포털의 최신 참가 유형·산업분류·알고리즘·첨부 제한·마감 확인.
- Work Studio에서 실제 지원 분석 실행. 로지스틱 회귀 지원 여부와 Python 모델과의 동등성은 미확인.
- 실제 데이터·그림 업로드 전 이용조건·포털 활용 동의 범위 검토.

공식 공고 URL은 이번에도 웹 도구로 열리지 않아 최신 변경 여부를 확정하지 못했다. 저장소 보관 PDF와 기존 요건 정리를 참고하되, 최종 포털 확인을 대체하지 않는다.

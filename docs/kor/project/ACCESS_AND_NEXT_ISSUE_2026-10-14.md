# 권한 및 다음 이슈 실행 가능 여부

점검일: `2026-10-14` (Asia/Seoul). 비밀값을 출력하지 않고 설정 유무만 확인했다.

## 권한·인증 점검

| 항목 | 확인 결과 | 필요한 조치 |
| --- | --- | --- |
| 로컬 점포·매출 분석 | 입력·예측·평가표·메타데이터 존재, 테스트 13개 통과 | 추가 권한 없음 |
| Linear 조회 | COD-198~200 상세·의존성 조회 성공 | 조회를 위한 추가 API 키 불필요 |
| 서울 열린데이터 API | `SEOUL_OPEN_DATA_API_KEY`가 로컬 `.env`와 프로세스 환경 모두 미설정 | 공식 유동인구 API 수집 시 키 필요. 공식 CSV를 별도 확보하면 해당 경로에는 API 키 불필요 |
| GitHub 자동 이슈·PR 구성 | 로컬 `LINEAR_API_KEY`·`GH_PAT` 미설정. 저장소 Secrets는 이번 점검에서 확인하지 않음 | 자동화 실행 시 저장소 Secrets의 두 키 확인. 로컬 미설정만으로 저장소 미설정을 단정하지 않음 |
| Work Studio·포털 | 현재 연결 도구에 전용 실행·브라우저 도구 없음 | 사용자 로그인 환경에서 재현·최종 요건 확인 필요. 계정 비밀번호를 채팅으로 전달하지 않음 |

서울 API 키는 저장소 루트 `.env`의 `SEOUL_OPEN_DATA_API_KEY`에 로컬로 설정한다. 키 자체는 채팅·문서·Git에 넣지 않는다. 후속 작업에서 `fetch-footfall` 공식 API 수집 명령과 로컬 `.env` 로딩을 구현하고, 전체 페이지·총 건수·분기·중복·결측 검사 테스트를 추가했다. 실제 인증 수집은 키가 없어 미실행이다. 상세 현황은 [추가 데이터 검토](../research/ADDITIONAL_DATA_FEASIBILITY.md)를 따른다.

GitHub 자동화는 `.github/workflows/prepare-feature-pr.yml` 기준 `LINEAR_API_KEY`, `GH_PAT`를 사용한다. 저장소 규칙의 PAT 권한은 대상 저장소 Contents 읽기, Issues 및 Pull requests 쓰기다. 이는 로컬 모델 검증을 시작하기 위한 조건이 아니다. 외부 서비스 기록 변경·업로드·제출 승인은 인증정보 설정과 별개다.

## 다음 이슈 판정

Linear의 의존성은 `COD-197 → COD-198 → COD-199`, 별도로 `COD-197 → COD-200 → COD-201`이다. 세 이슈 모두 Todo이며 COD-198~200의 상세 설명에 개별 완료 조건은 작성되어 있지 않다. 아래는 저장소 모델 계약과 관측한 한계에 따른 실행 제안이다.

| 이슈 | 판정 | 다음 구체 작업 |
| --- | --- | --- |
| COD-198 결과 검증·튜닝 | 기존 점포·매출 범위에서 바로 진행 가능 | 검증 분기만으로 파라미터 비교, 점포 규모별 검증·임계값 검토, 매출 변수 제외 비교, 상권 단위 재표집으로 성능 차이 불확실성 추정 |
| COD-199 결과 해석 | 초안 보강 가능, 확정은 검증 결과 반영 후 | 규모 효과와 추가 변수 기여, 소규모 집단 미포착 사례 정리 |
| COD-200 시각화·본문 | 기존 그림 보강 가능 | 업종·규모별 성능과 표본 수 그림, 소규모 집단 한계 캡션 추가 |
| COD-195 공식 인구 확장 | API 키 또는 공식 파일 확보 필요 | 수집기 구현 후 원천 품질·결합률 검증, 현 점포·매출 전용 모델과 별도 비교 |
| COD-197 지원 분석 재현 | Python 실행 결과 확보, Work Studio는 미완료 | 사용자 접근 가능한 Work Studio에서 동일 입력·분할·지표 대조 |

추가 실험에서도 기존 평가 기간은 이미 확인한 탐색 자료임을 유지한다. 평가 성능을 보면서 임계값을 최적화하지 않는다. 새 독립 기간 확보 전에는 확증 성능으로 표현하지 않는다. 공개일·자치구 매핑은 자료 확보와 구현 문제이며 추가 계정 권한이 반드시 필요한 것으로 확인된 것은 아니다.

COD-197 전체 완료 전에도 기존 이슈가 허용한 점포·매출 예외 경로로 COD-198의 검증 작업은 진행할 수 있다. 최초 점검 뒤 COD-198~200 검증, COD-201~202 로컬 자료 묶음, 자치구 검증과 과거 기간 실험을 실행했다. 전체 이슈 완료·외부 제출 준비 완료와는 구분하며 외부 이슈 상태는 변경하지 않았다.

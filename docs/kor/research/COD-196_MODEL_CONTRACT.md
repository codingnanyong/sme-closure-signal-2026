# COD-196 점포·매출 모델 계약

작성일: `2026-10-14` (Asia/Seoul). 관련 이슈: COD-195~198.

## 분석 범위

서울 상권×서비스업종×분기를 분석한다. 타깃은 바로 다음 분기에 폐업 점포가 하나 이상 있는지다. 개별 사업자의 폐업확률이나 노출 점포당 폐업률을 추정하지 않는다. 공식 점포·추정매출 2024~2025년 파일만 사용하고, 미리보기 길단위인구는 제외한다. 기존 시험용 `model_dataset.csv`는 보존하고 `stores_sales_dataset.csv`를 별도로 생성한다.

점포 1개 이상과 연속 다음 분기 타깃이 있는 행을 포함한다. 1개 기준은 소규모 집단의 배제를 줄이는 운영 가정이며 통계적 안정성이 보장되는 기준은 아니다. 5개·10개 기준의 결과도 같은 모델로 비교한다. 이 비교는 재학습 결과가 아니다. 점포 0개·결측은 제외하고, 매출 결측은 0원으로 간주하지 않는다.

## 변수와 결측 처리

| 변수 | 산식·시점 | 결측 처리 |
| --- | --- | --- |
| 점포·폐업·개업 수 | t의 각 건수에 log(1+x) | 학습 중앙값 |
| 추정매출 | t의 금액에 log(1+x) | 학습 중앙값과 결측 표시 |
| 매출 변화 | log(1+매출_t) − log(1+매출_t-1) | 연속 분기만 계산, 학습 중앙값과 표시 |
| 매출 변동성 | 최근 연속 3개 매출 변화의 모집단 표준편차 | 4개 연속 분기 미확보 시 결측, 학습 중앙값과 표시 |
| 업종 | t의 서비스업종 코드 | 학습 OneHotEncoder, 새 업종은 전체 0 |

중앙값·표준화·업종 인코딩은 학습 자료에만 적합한다. `sales_missing`과 imputer의 매출 결측 표시가 중복되지 않도록 수치 입력에서는 전자를 제외한다. 상권코드·상권명·공개 폐업률·미래 타깃은 피처로 넣지 않는다. 점포 수는 경쟁밀도 자체가 아니라 노출 규모의 대리지표다.

## 기준선과 후보

1. 학습 기간 업종별 미래 폐업 발생 평균. 새 업종에는 전체 학습 평균 적용.
2. t의 폐업 발생 여부. 미래 타깃 관점에서 직전 관측 폐업 발생 기준선이다.
3. 동일 분기 내 매출 하락·매출 변동성·점포 수 백분위의 동일 가중 평균. 결측 백분위는 0.5. 점포 수를 경쟁밀도로 확정 해석하지 않는다.
4. 점포 수·업종만 사용하는 로지스틱 회귀. 규모 효과를 통제하는 추가 기준선이다.
5. 전체 후보 변수의 로지스틱 회귀.

로지스틱 회귀는 `C=1.0`, `solver=lbfgs`, `max_iter=1000`, `random_state=0`, 클래스 가중치 없음. 수렴 여부를 검사한다. 트리 모델 탐색은 이번 최소 실행 범위에서 제외한다.

## 시간 분할과 선택

- 학습 피처: 2024Q1~Q4, 라벨: 2024Q2~2025Q1.
- 검증 피처: 2025Q1, 라벨: 2025Q2. 검증 AP로 모델 선택, 각 모델의 검증 F1 최대값으로 임계값 선택.
- 평가 피처: 2025Q2~Q3, 라벨: 2025Q3~Q4. 학습·임계값 고정.
- 평가 자료는 재학습에 넣지 않는다. 점포 수·업종 기준선은 첫 분석에서 규모 의존성이 관측된 후 추가했으므로, 전체 비교는 탐색적 결과이며 완전히 독립된 확증 실험은 아니다.

최종 비교 지표는 Average Precision(AP), F1, 정밀도·재현율, 상위 20% 정밀도·포착률이다. AP는 PR 곡선의 계단 적분값으로, 사다리꼴 PR-AUC와 구분한다. 평가 기간 전체와 분기별 비교를 모두 저장한다. 전체 기간 상위 20%와 분기별 상위 20%는 모집단이 달라 결과가 다를 수 있다.

위험 5분위는 각 분기 내 선택 모델 점수의 순위로 계산한다. 5가 가장 높다. 동점은 상권·업종 코드 순으로 나누므로 점수 차이가 없는 행의 분위가 달라질 수 있다. 모델의 이진 임계값과 분위 기준은 별개다.

## 검증 범위와 남은 한계

시간 순서 분할은 분기 데이터의 실제 공개 지연을 재현하지 않는다. t 분기 자료가 공개된 이후의 후향 분석이며, 실제 운영 전에 파일별 공개일과 수정 이력을 확보해 의사결정 시점을 재설정해야 한다. 학습 마지막 라벨 분기와 검증 피처 분기가 같은 것은 해당 분기의 자료가 모두 공개된다는 가정이다.

업종·점포 규모·분기별 표본 수와 성능을 저장한다. 자치구 매핑 자료가 없어 자치구별 성능 검증은 미완료다. 반복 상권의 상관을 고려한 신뢰구간, 외부 기간 검증, 길단위인구 추가 비교도 미완료다. 높은 점포 수에서 폐업이 하나라도 관측될 가능성이 커지는 구조적 효과를 반드시 함께 설명한다.

생성형 AI는 분석 코드·테스트·문서 초안 작성과 결과 요약에 사용했다. 사람의 데이터 해석·제출 문구 검토는 별도 완료 기록이 필요하다.

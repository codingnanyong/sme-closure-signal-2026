# COD-192 폐업위험 조기신호 가설

확인 기준일: `2026-09-18`

## 의사결정 문제

지자체와 소상공인 지원기관이 상담·경영개선·금융지원을 집중 검토할 `상권×서비스업종`을 분기별로 조기에 선별한다. 결과는 개별 사업자의 폐업을 단정하거나 지원을 자동 배제하는 수단이 아니라 지역·업종 단위의 선제 점검을 돕는 보조지표다.

## 분석 단위와 예측 정의

- 분석 단위: 서울시 `상권코드×서비스업종코드×기준년분기`
- 관측창: 기준 분기 `t`를 포함한 직전 4개 분기
- 예측창: `t+1` 분기
- 기본 타깃: `t+1`의 폐업 발생 여부, 즉 `CLSBIZ_STOR_CO > 0`
- 보조 타깃: `t+1` 폐업 점포 수. `t`의 노출 점포 수를 명시하고 최소 표본 기준을 적용한다.
- 사용하지 않는 타깃: 공개 `CLSBIZ_RT`를 폐업확률로 직접 사용하지 않는다. 100 초과 값이 있고 다운로드 스키마만으로 분모가 완전히 확인되지 않았다.
- 계획 기간: `2021Q1~2025Q4`; 현재 구조·결합 실측 범위는 `2024Q1~2025Q4`

## 검증할 가설

1. 최근 2~4개 분기의 추정매출 증감률이 낮을수록 다음 분기 폐업 발생 가능성이 높다.
2. 매출 증감률의 변동성이 클수록 다음 분기 폐업 발생 가능성이 높다.
3. 길단위인구의 전년 동기 대비 증감률이 낮을수록 다음 분기 폐업 발생 가능성이 높다.
4. 동일 상권·업종의 점포 수 또는 개업률이 급격히 늘어난 구간에서 다음 분기 폐업 발생 가능성이 높다.
5. 매출 하락·인구 하락·경쟁 심화가 함께 나타나는 집단은 개별 신호만 나타난 집단보다 다음 분기 폐업 발생률이 높다.

가설은 방향을 제안한 것이며 아직 분석 결과가 아니다.

## 검증 규칙

- 학습·검증을 무작위로 나누지 않고 시간 순서로 나눈다.
- `t+1` 폐업 정보와 미래 집계값을 `t` 설명변수에 포함하지 않는다.
- 직전 폐업 발생 또는 업종별 과거 평균을 단순 기준선으로 둔다.
- 불균형 자료이므로 정확도보다 상위 위험군 정밀도·재현율·F1·PR-AUC를 우선한다.
- 위험 5분위별 실제 폐업 발생률이 단조 증가하는지 확인한다.
- 자치구·업종·점포 규모별 성능 편차와 표본 수를 함께 공개한다.

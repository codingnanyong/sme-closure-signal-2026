# COD-192 서울시 상권 데이터 검증 결과

검증 기준일: `2026-09-18`

이 문서는 서울 열린데이터광장에서 내려받거나 조회한 원자료의 구조와 결합 가능성을 확인한 기록이다. 원자료는 라이선스와 용량을 고려해 저장소에 포함하지 않는다. 수치는 `2024Q1~2025Q4` 점포·매출 파일과 `2024Q1`, `2025Q1` 길단위인구 조회 결과에 한정된 측정값이다.

출처 표시 예시: `서울특별시 서울 열린데이터광장, 서울시 상권분석서비스, 공공누리 제1유형`.

## 2. 확인한 키와 핵심 컬럼

- 공통 결합 키: `STDR_YYQU_CD`(기준년분기), `TRDAR_CD`(상권코드)
- 점포·매출의 업종 키: `SVC_INDUTY_CD`(서비스업종코드)
- 점포: `STOR_CO`, `SIMILR_INDUTY_STOR_CO`, `OPBIZ_RT`, `OPBIZ_STOR_CO`, `CLSBIZ_RT`, `CLSBIZ_STOR_CO`
- 매출: `THSMON_SELNG_AMT`, `THSMON_SELNG_CO`
- 길단위인구: `TOT_FLPOP_CO`; 업종 키가 없으므로 같은 상권의 업종 행에 공통 설명변수로 결합한다.

모델 테이블의 기본 단위는 `분기×상권×서비스업종`으로 정한다. 길단위인구는 `분기×상권`에서 먼저 유일성을 확인한 뒤 업종 행에 확장한다.

### 폐업 타깃 품질

| 항목 | 측정값 |
| --- | ---: |
| 폐업 점포 수가 1 이상인 행 | 68,042 / 611,664 (11.124%) |
| `CLSBIZ_RT` 결측 | 0 |
| `CLSBIZ_STOR_CO` 결측 | 0 |
| 폐업률 중앙값 / 95% / 99% / 최댓값 | 0 / 13 / 50 / 450 |
| 폐업률 100 초과 | 348행 |
| 현재 점포 수 0 | 21,385행 |
| 폐업 점포 수가 현재 점포 수보다 큼 | 5,992행 |

`CLSBIZ_STOR_CO / STOR_CO × 100`은 공개 폐업률과 평균 절대오차 0.394로 가깝지만, 현재 점포 수가 0인데 폐업 건수가 있는 행과 100 초과 폐업률이 존재한다. 따라서 공개 폐업률은 확률로 해석하지 않고, 제공기관의 정확한 분모 정의를 확인하기 전까지 참고 지표로만 쓴다.

### 모델 입력 생성 시험

`python -m sme_closure_signal build`로 2024Q1~2025Q4 자료를 결합해 로컬 모델 입력을 생성했다. 연속된 다음 분기 타깃이 있는 행은 531,670개였고, 그중 다음 분기 폐업 발생 비율은 10.920%였다. 마지막 분기와 중간 분기가 끊긴 집단은 `target_available=0`으로 표시해 학습 대상에서 제외한다. 생성 CSV는 재현 가능한 중간 산출물이므로 저장소에 커밋하지 않는다.

## 4. 게이트 판정과 설계 결정

| 게이트 | 판정 | 결정 |
| --- | --- | --- |
| 공통 키와 기간 | 통과 | 점포·매출은 정확 키 결합 가능 |
| 2024년 공간 단위 변경 | 조건부 통과 | 2024Q4→2025Q1 연속성은 높음. 2021~2023 연결은 별도 코드 안정성 검증 필요 |
| 타깃 가용성 | 조건부 통과 | `t+1` 폐업 발생 여부 또는 폐업 건수를 사용. 공식 폐업률을 확률 타깃으로 직접 사용하지 않음 |
| 인구 데이터 확보 | 조건부 | 구조와 Q1 결합률은 확인. 전 기간 공식 API 수집은 인증키 필요 |
| 라이선스 | 통과 | 공공누리 1유형 출처 표시. 원자료는 저장소에 재배포하지 않음 |

최종 분석 단위는 `분기 t×상권×업종`이다. 기본 타깃은 `t+1`의 폐업 발생 여부(`CLSBIZ_STOR_CO > 0`)로 두고, 폐업 건수 모델은 `t`의 노출 점포 수를 명시한 보조 분석으로 둔다. 점포 수가 너무 작은 집단의 불안정성을 줄일 최소 노출 기준은 학습 데이터 분포를 본 뒤 COD-195에서 고정한다.

## 5. 재현 방법

- 데이터 검증: `python -m sme_closure_signal validate`
- 모델 입력 생성: `python -m sme_closure_signal build`
- 타깃 기술통계: `python -m sme_closure_signal summarize`
- 길단위인구 구조 확인 보조도구: `python -m sme_closure_signal.preview`
- 원자료 파일과 API 인증키는 커밋하지 않는다.
- 본 문서 수치는 스크립트 출력에서 옮겼으며, 전 기간 수집 후 같은 검사를 다시 실행해 갱신한다.

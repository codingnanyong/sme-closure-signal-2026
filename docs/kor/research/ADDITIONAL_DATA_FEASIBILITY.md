## 1. 공식 유동인구 수집 준비

공식 API 명세의 서비스명은 `VwsmTrdarFlpopQq`이며 분기 인자를 지원한다. 현재 다운로드 파일은 표시되지 않고 API·Sheet 인터페이스가 안내되어 있다. Sheet 미리보기를 정식 수집으로 대체하지 않는다.

사용자가 루트 `.env`의 `SEOUL_OPEN_DATA_API_KEY`에 인증키를 설정하면 다음 명령으로 2024~2025년 8개 분기 전체를 요청할 수 있다. 키를 채팅에 붙이지 않는다.

```powershell
.\.venv\Scripts\python -m sme_closure_signal fetch-footfall
```

수집기는 1,000행 단위 페이지의 총 건수 일치, 분기 일치, 키 중복·결측, 인구 값의 숫자·음수 여부를 검사한다. 성공 시 `data/raw/seoul/footfall/official-2024-2025.csv`와 키를 제외한 출처·SHA-256 JSON을 생성한다. `sample` 키는 전 기간 수집에 허용하지 않는다. 실제 인증 호출과 전 기간 자료의 완전성은 아직 검증하지 않았으며, 현재 명령은 키 미설정 안내로 종료되는 것을 확인했다.

수집 후에는 기존 매출 제외 후보와 `인구 수준·연속 분기 변화·전년 동기 변화` 추가 후보를 같은 대상 행·시간분할로 비교한다. 상권 단위의 모든 업종에 같은 인구 값이 붙으므로 실제 업종별 고객 수로 표현하지 않는다. 전년 동기 피처는 과거 자료가 없는 초기 분기의 결측과 가용성 편향을 별도 확인한다. 공개일을 확인하기 전에는 실시간 조기경보 효과를 주장하지 않는다.

## 2. 자치구별 검증 보완

공식 영역 ZIP의 DBF 속성에서 상권코드·자치구코드·자치구명을 읽었다. 코드로 직접 연결했으며 명칭 추정이나 좌표 기반 임의 배정은 하지 않았다. 매핑 키 중복·결측은 없었고 평가 147,032행의 결합률은 100%다.

고정 v1 후보의 자치구별 AP는 도봉구 0.3476에서 강남구 0.5949까지 분포했다. 두 자치구의 양성 비율도 각각 8.8817%, 13.3849%로 다르므로 AP만으로 모델 편향이나 지역 위험도를 단정하지 않는다. 지역별 표본·업종·점포 규모 구성의 차이를 같이 검토해야 한다.

이 파일의 페이지상 수정일은 2023-10-23, 데이터셋 메타 갱신일은 2026-09-11이다. 분기별 경계 이력은 아니므로 역사적 경계의 동일성을 증명하지 않는다. 지역별 사후 검증에만 사용했으며 학습 피처로 넣지 않았다.

```powershell
.\.venv\Scripts\python -m sme_closure_signal download-areas
.\.venv\Scripts\python -m sme_closure_signal audit-districts
```

산출물은 `outputs/validation/districts/area_district_mapping.csv`, `district_performance.csv`, `provenance.json`이다. 기존 문서의 ‘자치구 검증 미완료’는 1차 실행 당시 상태이며, 이번 스냅샷 기반 검증으로 일부 보완되었다. 역사적 경계·지역별 추가 기간 검증은 남아 있다.

## 3. 2023년 추가 학습 가능성

2023년 점포의 1,650개 상권코드는 2024Q1의 1,650개와 모두 겹친다. 2023Q4의 상권·업종 쌍 77,056개 중 76,579개가 2024Q1과 겹쳤다. 이는 연결 가능한 코드의 측정값이며 2024년 전후의 정의·공간 경계가 완전히 동일하다는 증거는 아니다.

점포·개업·폐업 수와 업종을 사용하는 동일 회귀 C=10에 대해 학습 기간만 늘렸다. 검증은 2025Q1, 평가는 2025Q2~Q3의 같은 147,032행·같은 타깃을 유지했다. 임계값은 각 모델의 검증 F1으로만 정했다.

| 학습 기간 | 학습 행 수 | 검증 AP | 평가 AP | 평가 F1 |
| --- | ---: | ---: | ---: | ---: |
| 2024년 | 296,131 | 0.490961 | 0.486218 | 0.466272 |
| 2023~2024년 | 593,081 | 0.491296 | **0.487037** | **0.467438** |

평가 AP 증분은 **0.000819**, 상권 단위 paired bootstrap 500회·시드 198의 95% 백분위 구간은 **[0.000494, 0.001153]**이다. 이번 기간에서 작은 개선 가능성을 확인했다. 모델 재학습·기간 변화·모델 선택의 불확실성은 반영하지 않았고 이미 본 평가 기간을 재사용한 탐색 결과다. 큰 개선·확증 성능으로 표현하지 않는다.

기준 모델의 AP·F1은 v1과 일치한다. 상위 20% 지표는 동점에서 입력 행 순서 영향을 받아 v1과 아주 작은 차이가 있을 수 있다. 이번 비교는 두 모델에 같은 분기·상권·업종 순서를 적용했다. 과거 기간 자료는 현재 내려받은 스냅샷이므로 당시 공개일·수정 이력과 기존 2024~2025 파일의 스냅샷 차이도 검토해야 한다.

```powershell
.\.venv\Scripts\python -m sme_closure_signal collect-history --year 2023
.\.venv\Scripts\python -m sme_closure_signal evaluate-history
```

원천은 `data/raw/seoul/history/`, 비교 결과는 `outputs/models/history_extension/`에 있다. 제출 검토용 v1의 입력·평가표는 덮어쓰지 않았다. 경계·기준시점 검토를 거친 뒤 v2 채택 여부를 판단한다.

## 다음 순서

1. 로컬 v1 자료 묶음과 Work Studio 인계 자료를 사람 검토에 사용한다.
2. API 키가 설정되면 공식 유동인구 8개 분기를 수집·품질 검사하고, 동일 표본 비교로 추가 기여를 측정한다.
3. 2023년 자료의 정의·공간 경계와 실제 공개시점을 확인하고 과거 기간 확장 후보의 채택 여부를 결정한다.
4. 실제 추가 기간이 확보되면 모델·임계값을 고정한 독립 검증을 우선한다. 매출·인구·기간을 반복 선택한 기존 평가 기간을 새 검증 자료로 부르지 않는다.

직장·상주인구나 다른 자료를 무조건 늘리는 것보다 현재 확인된 규모 의존성, 공개시점, 독립 검증을 먼저 보완한다. 생성형 AI는 수집·분석 코드, 테스트, 문서와 결과 요약에 사용했으며 사람 검토 기록은 별도로 남긴다.

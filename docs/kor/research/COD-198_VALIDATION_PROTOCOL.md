# COD-198 추가 검증 계약

작성일: `2026-10-14` (Asia/Seoul). 기존 [모델 계약](COD-196_MODEL_CONTRACT.md)의 시간 분할·원천·타깃 정의를 유지한다. 본 실험은 이전 평가 기간을 확인한 뒤 설계한 후속 탐색 분석이다.

## 검증 질문

1. 점포 수·개업·폐업 수와 업종을 고정할 때 매출 관련 변수를 추가하는 것이 AP를 높이는가?
2. 같은 상권 안의 업종과 분기 간 의존성을 고려해도 모델 간 AP 차이가 유지되는가?
3. 소규모 집단에 별도 임계값을 적용할 때 포착률과 정밀도, 점검 대상 건수는 어떻게 달라지는가?

## 검증 분기만 사용하는 튜닝

2024Q1~Q4 피처로 학습하고 2025Q1 검증 AP로 각 모델군의 C를 `0.1, 1.0, 10.0` 중 선택한다. 동점이면 먼저 평가한 작은 C를 선택한다. 선택한 C의 회귀만 2025Q2~Q3 평가 기간에 적용한다. 전처리는 각 학습 파이프라인에서만 적합하고 반복 횟수 1,000 미만으로 수렴했는지 검사한다. 선택한 모델군 중 검증 AP가 가장 높은 모델을 후속 검토 후보로 삼는다. 이진 임계값은 그 모델의 검증 F1 최대값으로 정한다.

모델군은 전체 후보, 매출 제외 후보, 점포 수·업종 기준선이다. 매출 제외 후보에서는 `log_sales`, `sales_change`, `sales_volatility`와 해당 결측 표시를 모두 제거한다. 점포·개업·폐업 수와 업종은 유지한다. 원천에 매출 결측 여부가 간접적으로 남아 있는 추가 변수를 넣지 않는다. 전체 후보와 동일 C를 사용한 매출 제외 모델도 별도 비교하여 정규화 강도 차이를 구분한다.

## 상권 단위 paired bootstrap

평가 자료의 상권코드를 군집으로 삼아 원래 상권 수만큼 복원 추출한다. 한 상권에 속한 모든 업종과 두 평가 분기에 같은 반복 가중치를 준다. 각 반복에서 모든 모델에 동일 군집 가중치를 적용한 뒤 AP와 AP 차이를 계산한다. 군집 수 1,650개, 반복 500회, 난수 시드 198이며 2.5·97.5 백분위 구간을 보고한다.

계산은 점수 정렬·동점을 보존한 가중 AP로 수행하며, 테스트에서 scikit-learn의 `sample_weight` AP 및 동일 군집 복원 추출 결과와 대조한다. 동일 모델 비교의 AP 차이는 모든 반복에서 0이어야 한다.

구간은 **고정 학습 모델·두 평가 분기에 조건부인 상권 표본 변동성**이다. 모델 재학습, 연도·경기 충격, 공간적으로 인접한 다른 상권의 의존성, 튜닝·모델 선택의 불확실성을 포함하지 않는다. 평가 기간을 이미 확인했으므로 확증적 유의성이나 인과효과를 주장하지 않는다.

## 규모별 임계값 진단

점포 수를 1~5, 6~10, 11~30, 31개 이상으로 나눈다. 각 규모의 검증 자료에서 F1 최대 임계값을 선택해 평가에 고정 적용한다. 검증 표본 100행 미만, 양성 20행 미만 또는 단일 클래스면 전역 임계값을 사용한다. 검증에 없던 규모도 전역 임계값으로 대체한다.

전역 임계값과 규모별 임계값의 정밀도·재현율·F1·점검 건수를 함께 저장한다. 동일 점검 예산에서의 비교가 아니므로 포착률 증가만으로 정책 개선을 선언하지 않는다. 자동 운영에는 도입하지 않으며 지원기관의 처리 용량과 오탐 비용 검토가 필요하다.

## 재현 및 산출물

```powershell
.\.venv\Scripts\python -m sme_closure_signal robustness --bootstrap-repeats 500 --seed 198
.\.venv\Scripts\python -m pytest -q -p no:cacheprovider
```

`outputs/models/robustness/`에 튜닝, 모델군 평가, 상권 재표집 구간·반복값, 규모별 임계값·정책 요약, 세부집단 평가, 예측값, 선택 후보의 분기별 5분위 관측 발생률, 메타데이터를 저장한다. `outputs/figures/robustness/`에는 매출 제외 비교·규모별 임계값 trade-off·업종별 성능과 표본 수·선택 후보 위험 5분위 그림의 PNG·SVG를 저장한다. 원천은 기존 점포·매출 전용 입력이며 SHA-256은 기존 매니페스트와 동일해야 한다.

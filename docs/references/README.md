# 공모 원문 자료

한국데이터산업진흥원의 [공식 공고](https://www.kdata.or.kr/datahub/portal/support/board/10/48)에 게시된 첨부파일을 원문 그대로 보관합니다. 요구사항을 해석할 때는 이 디렉터리의 PDF와 공식 페이지를 우선하고, 저장소의 요약 문서는 작업 편의를 위한 2차 자료로 사용합니다.

확인 기준일: `2026-09-18`

| 저장 파일 | 공식 첨부파일명 | 크기 | SHA-256 |
| --- | --- | ---: | --- |
| [통합공고문](2026-data-ai-innovation-challenge-notice.pdf) | `1. 「2026 데이터+AI 혁신 챌린지」 통합공고문.pdf` | 316,715 bytes | `32B6A878541339F9225FE95BE25AFB02BCE29B40ECC5673852B0A5375A0444C5` |
| [참가신청 양식](data-problem-solving-application-form.pdf) | `2. (데이터 문제해결) 참가신청 양식_F.pdf` | 242,215 bytes | `7A87B8781EA514F7C95EB55702E3F15DB27941EB1B1AC107880EC41A1FF2789C` |

두 파일은 공식 게시글의 첨부파일명과 바이트 크기를 대조했으며 일치합니다. 해시값은 저장소에 보관된 파일의 무결성 확인용입니다.

## 사용 시 주의사항

- 공식 게시글 본문 일부 평가 일정의 연도가 `2025`로 표기되어 있지만, 통합공고문과 2026년 전체 일정의 맥락상 `2026`으로 해석합니다.
- 참가신청 양식 PDF는 작성 항목을 미리 준비하기 위한 참고 양식입니다. 실제 신청은 포털 화면에서 직접 입력하며, 제출 시점의 포털 항목과 안내가 최종 기준입니다.
- 이 PDF는 공개 공고의 확인·검증용 사본이며 별도의 재사용 권한을 부여하지 않습니다. 저장소의 MIT 라이선스가 적용되지 않고 권리는 원저작자와 공고기관에 있습니다.

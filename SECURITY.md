# Security Policy

## 한국어

민감 정보(API 키, 개인정보, 인증 정보 등)가 노출된 것을 발견하시면 공개 Issue 대신 codingnanyong@gmail.com 으로 비공개 제보 부탁드립니다.

대회 제공 비공개 데이터나 재배포가 제한된 원천 데이터도 저장소에 올리지 않습니다. 이미 커밋된 민감 정보는 단순히 삭제하는 것으로 끝내지 않고 해당 자격증명을 즉시 폐기·재발급해야 합니다.

## English

If you discover exposed sensitive information (API keys, personal data, credentials, etc.) anywhere in this repo, please report it privately to codingnanyong@gmail.com rather than opening a public Issue.

Do not commit confidential competition data or source data whose terms prohibit redistribution. If a credential has been committed, revoke and rotate it immediately; deleting the file alone is not sufficient.

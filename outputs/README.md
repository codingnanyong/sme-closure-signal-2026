# 생성 산출물 영역

스크립트를 다시 실행해 만들 수 있는 결과는 Git에 커밋하지 않는다.

| 폴더 | 용도 |
| --- | --- |
| `validation/` | 품질·결합률 JSON과 로그 |
| `models/` | 학습 모델, 예측값, 평가표 |
| `figures/` | 레시피와 신청서에 사용할 그림 후보 |

검토가 끝난 핵심 수치와 해석만 `docs/kor` 문서로 옮긴다.

2026-10-19 원천·분석·제출 생성물을 재생성했다. [복구 기록](../docs/kor/project/LOCAL_RECOVERY_2026-10-19.md)에 경로와 검증 결과를 정리했다. 이 폴더의 생성물은 Git 복제에 포함되지 않으므로 환경을 옮길 때 별도 백업·이관 또는 재실행이 필요하다.
